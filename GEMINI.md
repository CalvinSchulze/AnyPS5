# AnyPS5 - Workspace Configuration & Execution Guidelines

## Auto Execution & Permissions
- Auto-execution is enabled for all tasks, commands, builds, and file edits in this workspace.
- The assistant is authorized to autonomously run build commands (e.g. Ninja, compiler toolchains), test suites, git commands, and file operations without prompting for manual confirmation.
- When performing changes, proceed immediately with implementation, verification, and debugging.
